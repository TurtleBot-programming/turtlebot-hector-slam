# Webots

Simulation of the TurtleBot 4 in a 10 m x 8 m test room. Run it with
`./run_sim.sh`. The full run guide is in the [top-level README](../README.md).

```
webots/
├── run_sim.sh        starts Webots + the ROS 2 bridge (--headless, --patrol)
├── worlds/           hector_slam_test.wbt (generated by tools/generate_world.py)
├── protos/           TurtleBot 4 PROTO; setup_meshes.sh copies the meshes
├── controllers/      tb4_ros2_bridge: extern controller publishing /scan,
│                     /odom, TF, /clock, /ground_truth/pose; subscribes /cmd_vel
├── maps/             ground_truth.{pgm,yaml} of the room (world frame)
└── tools/
    ├── layout.py         walls, obstacles, spawn pose, patrol route
    ├── generate_world.py regenerates the world and the ground-truth map
    ├── pose_logger.py    logs SLAM pose vs ground truth to CSV
    └── evaluate_map.py   scores a saved map (and pose log) against ground truth
```

`/ground_truth/pose` is relative to the spawn pose, the same frame as
Hector's `map`, so the two can be compared directly.
